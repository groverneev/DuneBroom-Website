# DuneBroom — AI Vision Rover for Measuring Shoreline Trash

The source for [dunebroom.com](https://dunebroom.com), a student-led robotics project: a low-cost rover that uses onboard AI vision to measure shoreline trash density (items/m²).

Created by [Neev Grover](https://neevgrover.com). The site covers the robot, its technical design, school outreach reaching 450+ students across five schools in India, and the children's book *Adventures of Sunbeam*.
